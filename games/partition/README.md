# Partition

Partition is ArcadeBench's continuous-control game. Guide a Spark along stable
boundaries, enter the live field to draw a vulnerable trace, and reconnect it
to partition the board. Regions without Anomalies stabilize; occupied regions
remain live.

The browser game and benchmark use the same deterministic headless engine.

```sh
npm run dev
npm test
```

The current `dev-0` build is a mechanics scaffold, not a frozen benchmark
generation. Rules and visuals may change until `partition-v1` is declared.
